# Práctica de Digitalización

En esta práctica he investigado cómo digitalizaría una empresa ficticia, Hermanos Almansa S.A, por lo que:

Usaríamos las tecnologías habilitadoras como cloud computing junto con el sistema ERP para automatizar y controlar la producción y el almacén, junto con la administración y la oficina técnica, para que todo esté intercomunicado y no se pierda información importante y previniendo errores. El IoT para sensores para el almacén también. Y a visión futura la IA para hacer marketing digital. Además, de la realidad aumentada y la automatización y robotización para la creación y control de los productos. 

**Otros imprescindibles:**
1. Conexión a internet o wifi
2. Formar al personal
3. Hacer los cambios gradualmente
4. Invertir en ciberseguridad
Estas necesidades junto con las anteriores, resuelve todos los problemas.

**ROI esperado:**
Se tendrá que invertir en una media de 57.000 euros y sacando beneficios de 75.000 euros, por lo que su ROI sería de un 31,5%.

En resumen, por cada euro invertido el primer año, la empresa recupera su inversión y gana 0,31€ adicionales. Para más adelante seguir con ventas y comercio.
